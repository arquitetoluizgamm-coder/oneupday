# Movimento do ONE

## Linguagem

Movimento significa respirar, crescer, guardar e voltar. Nunca pontuar, premiar ou pressionar.

| Situação | Movimento | Duração |
|---|---|---:|
| troca de aba | fade + 4px | 160ms |
| menu / modal | sobe 10px + fade | 180–220ms |
| apoio enviado | ícone se acomoda | 160ms |
| dia concluído | brilho curto sálvia | 420–520ms, uma vez |
| dia difícil | entrada calma, sem tremor | 180ms |
| recomeço | broto / luz aumenta | 500–700ms, uma vez |
| árvore | folha aparece e respira lentamente | 500ms + ciclo lento |
| cápsula aberta | luz interna e conteúdo revela | 240ms |
| loading | pulso de opacidade | 1,4s |

## Restrições

- Nenhum loop chamativo em cards do feed.
- Nada de confete contínuo, vibração agressiva ou contadores saltando.
- `prefers-reduced-motion` desativa transições decorativas e rolagem suave.
- A animação não pode ser a única forma de comunicar sucesso, erro ou novidade.
